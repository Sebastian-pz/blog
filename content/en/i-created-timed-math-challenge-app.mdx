I built an app for practicing addition, subtraction, multiplication, and division against a clock. The idea came from a class that timed how long we took to answer. I did fine. Several classmates did not.

Each round has a timer and a score. The score is stored per person, so a returning player can compare it with the previous round. There is no public leaderboard. The history belongs to the player.

If I pick it up again, the remaining work is a wider set of exercises. The current flow — operation, time, stored score — is already closed.

Stack: TypeScript, Vite, and Tailwind.
