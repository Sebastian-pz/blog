Across several projects I kept repeating the same code to read and write Excel with `xlsx`. The library covers the format. Every use repeated the same setup: open the workbook, find the sheet, map cells, and return the structure the rest of the application expected. That was not each product's logic. It was the same adapter.

I moved it into an npm package. The package wraps the `xlsx` calls I needed and exposes fewer functions. A consuming project imports that API and does not configure the library.

Publishing it changes maintenance. A parsing fix lives in the package, with its own version. The other repositories pick it up by updating the dependency, instead of copying the patch.

I can no longer find the tutorial I followed. [This one, in Spanish](https://www.youtube.com/watch?v=SgmkNLFFCjM), walks through the same process: package, version, and publish.
