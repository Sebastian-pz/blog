The degree project took more of my time that year than anything else. I wanted to use programming to read how clothing brands publish, instead of only describing it in prose.

I wrote a TypeScript program, organized in classes, that analyzes a brand's posts. The measures are concrete: principal colors, posting cadence, and interactions by kind of post.

At first it depended on a library that read accounts dynamically. I removed it because it did not meet the degree project's submission rules. The analysis stayed on a fixed set of posts.

## Input

For each brand I took the latest 150 posts. Each one was classified as product, meme, or phrase, with date, time, and principal colors.

## What it computes

- categories with the most interactions
- colors with the most interactions
- posts with the most interactions
- how many days pass between posts of each type
- deviation and chi-square
- the potential loss I defined in the project: interactions missed when the colors fall outside the category's palette
- categories present in the advertising pieces

That describes the pattern of a brand that already has an audience. It is there to compare one brand with another. The program does not include an experiment showing that copying the pattern works for a smaller brand.

Writing the tests was the part of the build I enjoyed most. The repository stayed with the advisor so other students could use it: [Sebastian-pz/TDG-2023](https://github.com/Sebastian-pz/TDG-2023).
