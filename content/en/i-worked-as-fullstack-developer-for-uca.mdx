In January 2023 I joined a team building a web app for Universidad Católica Argentina. The product simulates legal procedures: the sequence a law student walks through once they practice. The point was to rehearse the procedure and the tool before starting work.

I was hired as a fullstack developer. We worked in short iterations and with pair programming. The stack was Python, Node.js, TypeScript, Express, React, Redux, and Material UI.

The university approved the project. In the second semester of 2023 it went to production, and students started using it.

## What I did in the code

- The simulation on the client: steps of the procedure, the user's decisions, and the case state, in React and Redux.
- The API integration: reusable service functions, so HTTP calls were not scattered through components. A contract change was made in the service.
- The session, validated on the client and on the server. The role decided which routes and which actions each user saw. When the token expired, the client asked the server for a new one. If that request failed, it signed the user out.
- The interface, with the team, following the procedure's flow.
- On the server, also with the team: endpoints, the database connection, file upload, and sign-in.
- Pair programming to review that logic before integrating it.

The domain was not mine. Each screen had to follow a legal procedure, and that is what the engagement taught me.

Thanks to UCA.
