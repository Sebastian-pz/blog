I built a rock-paper-scissors web app in the gaps between university and freelance work.

The starting point was a Frontend Mentor challenge. The challenge asks for the interface. I added the rules so the round could be played.

The presentation is CSS, with no style framework. I wanted the practice on layout and on the visual states of a round: the player's hand, the machine's hand, and the score.

The rules live in React, in TypeScript. The component stores both hands, compares them, and updates the score. Vite runs the dev server and produces the production build.

The game is deployed at [rps-game-navy.vercel.app](https://rps-game-navy.vercel.app/).
