In late 2022 I asked Matias Straface and Mesila Hellrigl to build a social app based on what was then Twitter. We started in the first days of 2023. We called it Ducker. The name says it is a clone.

With what we knew, we moved fast. After a couple of days of pair programming, the backend could already publish, authenticate, and persist.

The API is Express on Node.js. Data lives in MongoDB. Sessions use JWT and the Google Auth Library. CORS allows the client's origin. Where a change had to arrive without a reload, we used WebSockets.

We moved to the interface after that. The visual reference was Twitter, plus the changes we wanted to try. Within about a week most views were up and the client was calling the API. Posting a Quak, liking, commenting, and favoriting worked.

The profile came next: photo, name, description, location, and interests. By then the API contract was familiar, and that part did not change it.

The rest was adjusting Sass and fixing bugs. There were fewer than I expected. I did not count them.

Stack: TypeScript on the client and the server, React, Sass, Express, MongoDB, JWT, Google Auth Library, CORS, and WebSockets. Files we did not migrate stayed in JavaScript.

My CSS at the time was weaker than Mati's and Meli's. On the interface they walked me through layout and specificity while we programmed.
